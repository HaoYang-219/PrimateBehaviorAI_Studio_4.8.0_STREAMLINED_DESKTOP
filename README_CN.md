# PrimateBehaviorAI Studio 4.8.0 · 简洁桌面版

> 本压缩包包含 **源代码和 Windows 安装包构建工程**，**不是已经编译的 Setup.exe**。在 Windows 或 GitHub Actions 完成构建后，最终使用者可以离线安装，无需安装 Python/Anaconda/pip。

## 普通实验人员如何操作

**1. 新建实验**：检测摄像头 → 选择 1–3 路 → **快速准备**（默认联合短测试）→ 系统自动显示实时画面 → 开始采集。画面按实际 4:3 或 16:9 比例适应布局，不再用固定 230 像素高的宽条显示。仅在连接异常时打开“高级摄像设置 / 完整诊断”。

**2. 视频质量**：默认“自动适配 · 优先30 FPS”；优先尝试该摄像头组合以前通过的模式，首次连接建议从 720p30 开始。只有当前模式联合失败才尝试 640p30。默认只扫描较常见的设备索引 0–5；摄像头未列全时在高级设置中点击“搜索更多摄像头”，可扫描 0–11。若选用自动低分辨率，正式录像前必须确认；录像过程中不会自动改变分辨率或帧率。软件仍会检测实际画面和帧率，不能以单独开机成功代替多路联合验证。要求指定 1080p30/720p30/640p30 时可手动选择，**手动模式不会自动降档**。高级模式里支持 60 FPS，但须看真实设备支持情况。

**3. 实验阶段**：录像持续不断；在“阶段与参数”输入载波、调制、信号强度、波形、天线距离和备注，切换 Baseline、刺激期、Recovery。软件只记录实际点击时间，不控制刺激仪。可正常停止保留数据，或二次确认后放弃试拍。默认无限时、无 300 s 自动停止。

**4. 分析数据**：无需选“三个分析模式”。录好的 Session 点击“选择实验文件夹…”自动识别 1–3 路；单独的视频点击“选择单个视频…”，如果需要与另一段视频比较再勾选“与另一段视频做前后对比”。各视角仍需独立 ROI 标定；高级阈值默认隐藏。

**5. 查看结果**：可直接从顶部下拉选择历史分析，默认展开完整宽度的 AI 候选事件表；点击“同步视频与事件复核”核对原始录像，标记确认、误报或无法判断；视频预览在独立 Tab，不再挤压 8 列事件信息。

**6. 历史实验、设置、帮助**：历史页支持关键字查找和多次实验比较导出；设置页只展示本地文件位置与诊断包，高级模型技术细节默认折叠；帮助页提供四步流程与常见故障。

## 输出文件

采集 Session 的顶层主要保留 1–3 路连续原始视频、`session_record.csv`、`session.json`、`采集验收报告.html`。逐帧时间戳与同步 QC 放在 `_metadata/`。

行为分析顶层主要为 `report.html`、`summary.csv`、`events.csv`；原始逐路详细分析保存在 `details/`。同步复核结果存入独立人工标注文件，不覆盖原始 AI 候选。

## 获得真正的 Windows Setup.exe

**推荐：GitHub Actions 自动构建**。详见 [docs/GITHUB_SETUP_CN.md](docs/GITHUB_SETUP_CN.md)。不需要在你的电脑安装 Python。GitHub 构建时会下载全部依赖，将它们封装成 Windows 安装程序。最后输出文件名为 `PrimateBehaviorAI_Setup_4.8.0_x64.exe`。

**可选：本地 Windows 构建**。构建电脑安装 Python 3.11 x64 和 Inno Setup 6，然后运行 `BUILD_INSTALLER.bat`。这仅对打包者有要求，**最终实验电脑无需这些工具**。

**重要：此 Linux 环境无法编译并实际验证 Windows Setup.exe；本包不能作为已完成的 Windows 安装包出售。** 先在真实 Windows 电脑安装并验证 1–3 路相机驱动、视频录制、停止/放弃、分析和复核。打包后的文件比较大是正常现象，因为解释器和依赖都包含在内。Qt、OpenCV、视频编解码与模型权利许可必须在商业发行前核查。

## 仍需验证的科研边界

- 自动视频质量配置只依据短时间**主机侧采集**表现；正式录制稳定性仍须持续监控，驱动繁忙或 USB 控制器共享带宽仍可引起异常。
- 普通 USB 摄像头的软件时间戳不等于硬件曝光同步；短促动作的跨视角对齐仍需人工或离线校正。
- 抽搐样/震颤样/低觉醒样均为科研视频候选，**不是医学诊断**；需要专家标注数据定量验证误报和漏检。
- 当前 ROI 标定仍需人确认，不能误称为基于训练模型的自动猴姿态分割。
- 目前尚未实现完整的长录像分段保护和断电恢复。请在正式实验前留足磁盘空间，并进行长时间试录。
