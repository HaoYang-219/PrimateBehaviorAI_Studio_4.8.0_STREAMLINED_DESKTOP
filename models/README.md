# External models

4.8.0 runs without external AI model weights; it uses classical computer vision, ROI tracking, state-conditioned motion features and event-specific heuristics.

SAM2 is **not** bundled or active. The application does not implement 3D pose reconstruction. Research candidate flags need expert verification.

Use the shared `%LOCALAPPDATA%\\PrimateBehaviorAI\\models` directory if integrating separately supported weights in a future version.
